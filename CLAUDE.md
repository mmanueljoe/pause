# Pause: code

Pause is a vault on Solana where every withdrawal waits,
so the owner or a trusted guardian can stop it.

## Source of truth

- docs/requirements.md
  - "Core rules": what the program must enforce
  - "Functional requirements" and "User stories": what to build
- If something isn't in the doc, ask before building it.

## Stack

- Solana program: Rust + Anchor, on devnet
- Website: React + Vite + TypeScript + Tailwind (from the create-solana-dapp Vite template)
- Solana in the website: `@solana/kit` 8, `@solana/kit-plugin-wallet` (Wallet Standard: Phantom, Solflare), `@solana/react` + SWR for live data. Not `@solana/react-hooks` (unmaintained)
- Routing: React Router; icons: `lucide-react`
- Program client: generated by Codama into `src/generated/pause` (never edit by hand)
- Backend: Supabase (guardian emails, alerts, automatic release)

## Commands

- Build program: `npm run program:build`
- Test program: `npm run program:test`
- Lint program: `npm run program:lint`
- Regenerate client after a program change: `npm run setup`
- Run website: `npm run dev`
- Check website (types, lint, format, build): `npm run check`

## Rules

- The vault rules live in the Solana program, never only in the website.
- Every withdrawal waits. There is no daily limit or instant withdrawal.
- Only the guardian can approve early. Release goes only to the named recipient.
- Every program action has tests for who is refused and when.
- Demo mode works on devnet only.
- Never commit secrets or private keys.
- Keep the program small: only the actions in the doc.

## How to work

- Plan before writing code, and say which user story it covers.
- Make small changes, run the tests, then move on.
- Record what was built before vs. during the hackathon in the README.

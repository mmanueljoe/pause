# Wallet icons

Official picker icons, used unchanged in the Connect wallet screen.

- phantom.svg: from the `icon` data URI in anza-xyz/wallet-adapter, packages/wallets/phantom/src/adapter.ts (matches https://docs.phantom.com/resources/assets).
- solflare.svg: from the `icon` data URI in anza-xyz/wallet-adapter, packages/wallets/solflare/src/adapter.ts.

In the app, show the icon the wallet itself provides through Wallet Standard (`wallet.icon`) instead of bundling these.
